# 密钥、秘密与事件处理

简要说明：你的密钥从不离开 Binance 应用，你的盐值从不离开你自己的电脑或你自己的私有仓库。Forewit 没有任何保存用户秘密的服务器。团队自己的密钥可以运行轮次、发布分数根，但无法修改任何预测、分数或结果，合约也不持有任何资金。

## 你的秘密

* **钱包密钥。** 由 Binance 应用中的 Binance Agentic Wallet 创建并保管。Forewit 从不接触，也从不索要。如果有人以 Forewit 的名义向你索要密钥、助记词或恢复码，那不是我们。
* **钱包会话。** 官方 Binance Agentic Wallet CLI 登录时创建，保存在运行它的电脑或云端沙盒中（`~/.baw`）。泄露的会话可以在钱包自身的限额内请求转账，因此与 Forewit 一起使用的 Agentic Wallet 里只放少量用于 Gas 的 BNB，并在每次会话结束时登出。
* **配对码。** 由官方 CLI 显示一次，由你在 Binance 应用中核对，几分钟内有效。不要在其他任何地方输入。Forewit 从不接触它。
* **盐值和回执。** 提交时由你这边的 forewit CLI 随机生成。保存在 `~/.forewit/`（仅你的账户可读），在手机路径中也保存在你自己的私有仓库里。如果在提交截止前泄露，别人可能提前看到你的预测。如果丢失，你将无法揭示，该轮计为弃权。揭示之后它本来就是公开的。

## 如果 Keeper 密钥泄露

在角色被撤销之前，攻击者可以：

* 创建不符合选题规则的轮次；
* 在某个开放轮次的最后 15 分钟内抢在我们的 Keeper 之前发布错误的市场基线，从而扭曲该轮的技能分（Brier 分数不受影响）；
* 发布错误的 ForewitScores 根，或撤销最新的两个根之一。

攻击者永远无法：修改或删除任何提交、揭示、结果或分数，阻止任何人揭示，或转移任何资产。

我们的处理：

1. 管理员在 ForecastLedger 和 ForewitScores 上撤销泄露密钥的轮次管理员角色。一旦管理员钱包有 Gas（正在为此充值），撤销在下一个区块生效。
2. 管理员把该角色授予新的 Keeper 密钥，并替换 GitHub 机密。
3. 管理员撤销任何错误的根，并重新发布正确的根。
4. 我们在 24 小时内在[更新日志](../reference/changelog.md)和 X 上公布受影响的轮次和交易。

## 如果管理员密钥泄露

管理员取消任何待处理的管理员转移，撤销所有非其授予的角色，并把管理员席位转移到新密钥或多签。管理员转移的 1 天延迟为此留出了时间。我们以同样方式公布事件。
