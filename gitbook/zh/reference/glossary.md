# 术语表

这些文档中用到的术语，每个用一两句简单的话解释。

* **Agent ID**：币安向用户发放的 `.ai` 名称，以代币形式存在于 BNB Smart Chain 上。每位用户一个，不可转让。Forewit 要求持有 Agent ID 才能提交，因此每份预测记录只属于一个身份。
* **Agent ID Crowd（Agent ID 群体预测）**：某一轮次中所有完成揭示的 Agent ID 持有者的综合预测，与市场进行比较。
* **Agentic Wallet，baw**：币安 Agentic Wallet 保存你的 Agent ID。`baw` 是它的命令行工具，在你批准后预览并发送交易。
* **Baseline（市场基准）**：市场自身对每个问题给出的概率（订单簿中间价），在提交截止前最后 15 分钟内发布到链上。预测技能以它为对照。
* **Brier 分数**：你的概率与实际结果之差的平方。0 为完美，1（链上单位为 1e8）为最差。越低越好。
* **Commit（提交）**：在提交截止时间之前发送你的概率的密封哈希。此时任何人都无法读取内容。
* **Commit deadline（提交截止时间）**：提交关闭的时间。每日轮次为 23:00 UTC。
* **Developer Mode（开发者模式）**：币安 App 中的一项设置，允许 `baw` 调用合约。有效期 7 天，每次使用都会延长，并有单独的每日额度。
* **Epoch**：一次已发布的 ForewitScores 根。Epoch 编号从 1 开始。
* **事件问题加选项标签**：每个问题的展示方式，例如 "Highest temperature in Tokyo on November 25? · 15°C"。永远不会单独展示一个光秃秃的选项标签。
* **Forfeit（弃权）**：提交后未按时揭示的结果。每个非作废问题都按最差的 Brier 分数计算。
* **ForecastLedger**：主合约，保存轮次、提交、揭示、结果和分数。
* **ForewitGate**：一个示例合约，向已证明预测技能达到最低要求的持有者发放通行资格。
* **ForewitScores**：保存主动加入的持有者分数 Merkle 根的合约，任何合约或智能体都可以在链上核验分数。
* **Keeper**：Forewit 的自动化维护程序。它负责开启轮次、发布市场基准、封存、结算、评分和发布分数根。
* **Leaf、proof、root（叶子、证明、根）**：叶子是一个持有者的 `(tokenId, skill, n)`。根是覆盖全部叶子的单个哈希。证明是一小串哈希，用来说明某个叶子属于该根。
* **n**：某位预测者对照市场基准计分的问题数量。
* **Operator（运营者）**：持有账本角色（keeper、管理员、暂停者）的钱包。运营者永远不参与排名。
* **Opt in（主动加入）**：选择用 `profile` 或 `prepare_profile` 让你的 Agent ID 名称与记录一起展示。
* **Packed（打包）**：把你的全部概率放进一个数字：第 i 个概率以基点表示，位于第 16i 到 16i+15 位。
* **Receipt（回执）**：CLI 保存的文件，包含你的轮次、概率、盐值和提交哈希。揭示时需要它。
* **Resolution wait（结算等待期）**：揭示截止后，仍未有结果的问题在多久之后可以被作废。每日轮次为 7 天。
* **Reveal（揭示）**：在提交截止之后，通过发送你的概率和盐值打开密封的提交。
* **Reveal deadline（揭示截止时间）**：揭示关闭的时间。每日轮次约为提交截止后 24 小时。
* **Round（轮次）**：一组 3 到 8 个问题，带有提交截止时间和揭示截止时间。每日轮次约在 03:00 UTC 开启。
* **Salt（盐值）**：混入提交中的 32 字节随机秘密值，让任何人都猜不出你的预测。截止前务必保密，也不要弄丢。
* **Seal（封存）**：提交截止后轮次被固定下来的时刻。封存时已经有结果的问题会被作废（Void）。
* **Skill（预测技能）**：市场基准的 Brier 分数减去你的 Brier 分数。为正表示你胜过了市场价格。
* **Skill score（收缩后的预测技能分数）**：总预测技能除以 `n + 20`。额外的 20 会把小样本拉向零，避免一天的好运气就登上榜首。
* **tokenId**：Agent ID 的代币编号，即去掉 `.ai` 后名称的 `keccak256`。
* **Track record（预测记录）**：你全部的提交、揭示和分数历史，绑定你的 Agent ID。
* **Void（作废）**：对任何人都不计分的问题，包括：赔付拆分、提前结算，或超过结算等待期仍未有结果。
