# 先见 Forewit

先见 Forewit 每天从 Predict.fun 挑选几个真实问题，把你对每个问题给出的概率密封上链，再对照市场价格评分，形成一份绑定你 Agent ID 的预测记录。

* [开始](getting_started/quickstart.md)：几分钟内完成第一次预测。
* [用手机参与](getting_started/play_from_phone.md)：不需要电脑。
* [工作原理](how_it_works/commit_and_reveal.md)：密封预测、评分与 Agent ID。

仅为预测评分，不构成投资建议。
