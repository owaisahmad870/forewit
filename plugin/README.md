# Forewit plugin for Claude Code

One install for the Forewit MCP server (pinned npm package `forewit`), the Forewit skill, and the `/forewit:forecast` command.

```
/plugin marketplace add owaisahmad870/forewit
/plugin install forewit@forewit
```

Then say "Forecast with Forewit" or run `/forewit:forecast`. Every transaction is shown as a wallet preview first and sends only after you type yes.

The skill file here is a copy of `agent/SKILL.md`; a test keeps them identical.
