# Forewit plugin for Perplexity

The Forewit skill plus the hosted read only connector at https://forewit.xyz/mcp (no sign in, never sends anything).

In Perplexity: Plugins, Add custom, Import plugin from GitHub, then paste this folder's address:

```
https://github.com/owaisahmad870/forewit/tree/main/perplexity
```

Perplexity only accepts remote connectors, so this edition uses the hosted one. It can show rounds, market prices, the leaderboard and your results. Sending a forecast needs your own wallet: use the Claude Code plugin (`plugin/`) or `npx forewit@latest start` on a computer.

The skill file here is a copy of `agent/SKILL.md`; a test keeps them identical.
